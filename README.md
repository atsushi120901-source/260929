# AURELIA — 空と海の未来都市

真珠色の塔とガラスのドームが夕暮れに輝く未来都市「オーレリア」を自由に探検できる、ブラウザ向けオープンワールド 3D ゲームです（Three.js 製）。

- **果てのない街** — 100m 四方のチャンク単位で、プレイヤーの周囲に都市を自動生成します。座標から街並みが決まるので、同じ場所に戻れば同じ景色が見られます。
- **パステルの空** — 夕暮れ・夜・昼・夜明けの 4 つの時間帯。空の色は建物やガラスの映り込みにも反映されます。
- **地区** — オーレリア中枢区（パール色の高層タワー・円盤型タワー）/ ドーム街 / 丘の住宅地 / 桜の庭園 / オーレリア湾（ボートが浮かぶ海と島々）
- **ランドマーク** — 海辺に面した巨大ガラスドーム「グランドドーム」、高さ 360m の展望デッキを持つ「セレスティア・スパイア」、円盤型タワー
- **ホバーポッド** — `F` でいつでも呼び出して空を飛べます。屋上や展望デッキに降りて歩くこともできます。
- **ルミナ結晶の収集** — 街中や屋上に光の柱が立つ結晶が散らばっています。取得状況はブラウザに自動保存されます。
- 空に浮かぶ飛行船、道路に沿って飛ぶポッドの交通、雨、影、柔らかな発光エフェクト、ミニマップ

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173 を開く
```

`index.html` を直接ダブルクリックしても動きません（Three.js の読み込みに Vite が必要です）。静的ファイルとして公開する場合は `npm run build` で `dist/` を生成し、Web サーバー（GitHub Pages など）に置いてください。

## 操作

| キー | 動作 |
| --- | --- |
| WASD | 移動 |
| マウス | 視点（画面クリックでマウスロック） |
| Shift | ダッシュ（ポッドではブースト） |
| Space | ジャンプ（ポッドでは上昇） |
| C | ポッドで下降 |
| F | ホバーポッドに乗る / 降りる / 呼び出す |
| T | 時間帯切り替え（夕暮れ → 夜 → 昼 → 夜明け） |
| R | 雨 ON/OFF |
| B | 発光エフェクト ON/OFF |
| G | 影 ON/OFF（重いときはOFFに） |
| ホイール | カメラ距離 |
| H | 操作ヘルプ表示切り替え |

## コード構成

| ファイル | 内容 |
| --- | --- |
| `src/main.js` | レンダラー、時間帯、入力、カメラ、HUD、ミニマップ、メインループ |
| `src/city.js` | チャンク生成と破棄、地区と海岸線の決定、建物・公園・ランドマーク・ボート、当たり判定 |
| `src/sky.js` | 空のシェーダー（グラデーション・太陽・雲）、空を映す環境マップ、海面、飛行船 |
| `src/player.js` | 歩行キャラクターとホバーポッドの操作・物理 |
| `src/traffic.js` | 道路に沿って飛ぶポッドの交通 |
| `src/textures.js` | 外壁・ドームのガラス・道路・水面のテクスチャ（Canvas で生成） |
| `src/rng.js` | シード付き乱数とバリューノイズ |

チャンク内の静的なメッシュはマテリアルごとに 1 つへ結合し、描画コール数を抑えています。描画距離は `src/main.js` の `new City(scene, { radius: 6 })` で調整できます。
