# NEO CITY Explorer

果てなく続く未来都市を自由に探検できる、ブラウザ向けオープンワールド 3D ゲームです（Three.js 製）。

- **無限に広がる街** — 100m 四方のチャンク単位で、プレイヤーの周囲に都市を自動生成します。座標からシードを作るので、同じ場所には何度来ても同じ街並みが現れます。
- **5つの地区** — セントラル区（超高層ビル群）/ ネオン商業区（ホログラム看板）/ ハビタット住宅区 / ファクトリー区 / グリーンドーム公園
- **セントラル・スパイア** — 原点にそびえる高さ 420m のランドマーク。頂上の展望デッキに特別なチップがあります。
- **ホバーカー** — `F` でいつでも呼び出して空を飛べます。ビルの屋上に着地して降りることもできます。
- **データチップ収集** — 街中や屋上に光の柱が立つチップが散らばっています。取得状況はブラウザに自動保存されます。
- 空飛ぶ車の交通、昼夜の切り替え、雨、ブルーム（発光）エフェクト、ミニマップ

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173 を開く
```

静的ファイルとして公開する場合は `npm run build` で `dist/` を生成します（相対パスで出力するので GitHub Pages などにそのまま置けます）。

## 操作

| キー | 動作 |
| --- | --- |
| WASD | 移動 |
| マウス | 視点（画面クリックでマウスロック） |
| Shift | ダッシュ（車ではブースト） |
| Space | ジャンプ（車では上昇） |
| C | 車で下降 |
| F | ホバーカーに乗る / 降りる / 呼び出す |
| T | 時間帯切り替え（夜 → 夕暮れ → 昼 → 夜明け） |
| R | 雨 ON/OFF |
| B | ブルーム ON/OFF（重いときはOFFに） |
| ホイール | カメラ距離 |
| H | 操作ヘルプ表示切り替え |

## コード構成

| ファイル | 内容 |
| --- | --- |
| `src/main.js` | レンダラー、空・雨・時間帯、入力、カメラ、HUD、ミニマップ、メインループ |
| `src/city.js` | チャンク生成と破棄、地区の決定、ビル・看板・公園・スパイア、当たり判定 |
| `src/player.js` | 歩行キャラクターとホバーカーの操作・物理 |
| `src/traffic.js` | 道路に沿って飛ぶ車の交通 |
| `src/textures.js` | 窓・道路・ネオン看板のテクスチャ（Canvas で生成） |
| `src/rng.js` | シード付き乱数とバリューノイズ |

チャンク内の静的なメッシュはマテリアルごとに 1 つへ結合し、描画コール数を抑えています。描画距離は `src/main.js` の `new City(scene, { radius: 6 })` で調整できます。
